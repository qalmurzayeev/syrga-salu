# Сырға салуға шақыру

Шақыру сайтындағы жұптың есімдері үлгі ретінде берілген.

Күн мен уақытты өзгерту үшін `index.html` ішіндегі `id="event-date"` жолынан `datetime` мәнін өңдеңіз. Конверттегі күн, күнтізбе және кері санақ сол мәннен жаңарады.

Сайтты компьютерде көру үшін `index.html` файлын браузерде ашыңыз.
